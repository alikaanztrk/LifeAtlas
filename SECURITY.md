# Security

LifeAtlas processes sensitive personal location history. Report issues involving unintended requests, privacy bypasses, unsafe imports, data disclosure, unsafe updates or deletion failures privately.

If the project repository offers GitHub private vulnerability reporting, use **Security → Report a vulnerability**. Otherwise contact the maintainer through a private channel they provide. Wait for a private channel before sharing vulnerability details.

Include the app build or revision, Chrome version, operating system, expected behavior, and what happened. Use an artificial fixture and artificial place names and coordinates. Exclude Timeline exports, personal coordinates or labels, session data, browser profiles, screenshots of real archives, and request logs containing private data.

See [the privacy notice](PRIVACY.md) for what the app stores, sends and deletes.
